
💰 Python Expense Tracker

A simple, command-line personal finance and expense tracking application built using Python. This mini-project allows users to effortlessly add, view, delete, and calculate daily expenditures.

✨ Features

• Add Expense: Record new expenses with a name/description and amount.
• View Expenses: Display a clean, numbered list of all recorded expenses.
• Calculate Totals: Automatically compute and display your total expenditure.
• Delete Expenses: Remove unwanted or mistyped entries by their list index.
• Data Persistence: Automatically saves and loads your records from a local text or CSV file (optional / built-in file handling)
